# Proyecto Semana 1 - Desarrollo Orientado a Objetos II

## Descripción

Este proyecto corresponde a la actividad formativa de la Semana 1 de la asignatura Desarrollo Orientado a Objetos II.

Se desarrolló un sistema para la empresa de reparto SpeedFast, aplicando los conceptos de Programación Orientada a Objetos en Java:

- Encapsulamiento
- Herencia
- Polimorfismo
- Sobrescritura de métodos (Override)
- Sobrecarga de métodos (Overload)

## Estructura del Proyecto

### Clase Base
- Pedido

### Clases Derivadas
- PedidoComida
- PedidoEncomienda
- PedidoExpress

### Clase Principal
- Main

## Funcionalidades

### Pedido Comida
- Verifica que el repartidor cuente con mochila térmica.

### Pedido Encomienda
- Realiza validación de peso y embalaje.

### Pedido Express
- Busca al repartidor más cercano con disponibilidad
